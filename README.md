# Apple Juice Boom

A juice box of apple juice that you can place like a block. Shift-click it with
an empty hand and it starts to fizz. Then the whole sky fills with explosions,
there's a giant boom, and your game crashes for real.

The game saves your world before the juice blows up, so you don't lose
anything. Only the player who shook the juice crashes; everyone else on a
server keeps playing.

Craft it from an apple, sugar and a glass bottle.

Fabric, for Minecraft 1.21.11 and 26.2. Needs Fabric API. Put it on the server
and in your game.
